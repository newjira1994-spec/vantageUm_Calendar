# 📋 邀请机器人到日历 - 详细操作指南

## 目标

邀请机器人（App ID: `cli_aa84163b89789ed3`）访问以下日历：
1. **new jira** 日历
2. **BO Coordinator** 日历（Meeting schedules 群组）

---

## 第一步：邀请机器人到 new jira 日历

### 操作步骤

#### 1.1 打开 Lark 日历
- 打开 Lark 应用（桌面版或网页版）
- 点击左侧的 **"日历"** 图标

#### 1.2 找到 new jira 日历
- 在左侧日历列表中找到 **"new jira"** 日历
- 如果找不到，可能需要先创建或订阅该日历

#### 1.3 进入日历设置
- 点击 "new jira" 日历名称旁的 **"..."** 或设置图标
- 选择 **"日历设置"** 或 **"Calendar Settings"**

#### 1.4 添加成员
- 找到 **"成员"** 或 **"成员管理"** 部分
- 点击 **"添加成员"** 或 **"Add Member"**

#### 1.5 搜索机器人
有两种搜索方式：

**方式 A: 通过 App ID 搜索**
- 在搜索框输入: `cli_aa84163b89789ed3`
- 查找机器人账号

**方式 B: 通过机器人名称搜索**
- 输入机器人的应用名称
- 或输入机器人邮箱（如果有配置）

**方式 C: 通过机器人用户搜索**
- 如果机器人有对应的 Lark 用户账号
- 搜索该用户名称

#### 1.6 添加并授权
- 找到机器人后，点击 **"添加"**
- 选择权限级别：
  - **查看者**: 只能读取事件
  - **编辑者**: 可以创建、编辑、删除事件 ✅ **推荐**
  - **管理员**: 完全权限
- 点击 **"确定"** 或 **"保存"**

---

## 第二步：邀请机器人到 BO Coordinator 日历

### 操作步骤

#### 2.1 进入 Meeting schedules 群组
- 在 Lark 左侧找到群组列表
- 点击进入 **"Meeting schedules"** 群组

#### 2.2 找到群组日历
有两种方式：

**方式 A: 通过群组信息**
- 在群组信息中查找 **"群组日历"** 或 **"Group Calendar"**
- 找到 **"BO Coordinator"** 日历

**方式 B: 通过日历应用**
- 打开日历应用
- 在左侧日历列表中找到 **"BO Coordinator"** 日历
- 通常群组日历会有群组标识

#### 2.3 进入日历设置
- 点击 "BO Coordinator" 日历的 **"..."** 菜单
- 选择 **"日历设置"**

#### 2.4 添加机器人成员
- 找到 **"成员管理"** 或 **"权限管理"**
- 点击 **"添加成员"**

#### 2.5 搜索并添加机器人
- 输入 App ID: `cli_aa84163b89789ed3`
- 或搜索机器人名称
- 找到后点击添加

#### 2.6 设置权限
- 授予 **"编辑者"** 权限
- 确保机器人可以读取和创建事件
- 点击 **"保存"**

## 🔧 故障排除

### 问题 1: 找不到机器人

**可能原因**:
- 机器人没有对应的用户账号
- 搜索关键词不正确

**解决方案**:
1. 检查机器人是否有用户账号
2. 尝试使用不同的搜索方式
3. 联系 Lark 管理员确认机器人配置

### 问题 2: 无法添加机器人

**可能原因**:
- 权限不足
- 日历类型不支持添加应用

**解决方案**:
1. 确认您有日历管理权限
2. 如果是组织日历，联系组织管理员
3. 尝试使用其他日历

### 问题 3: 添加后仍无法访问

**可能原因**:
- 权限未生效
- 日历 ID 不正确

**解决方案**:
1. 等待 5 分钟后重试
2. 检查日历 ID 是否正确
3. 重新运行验证脚本
